# Bounded independent leases

Implement Serve and focused tests with its API, package, dependencies and Go 1.22 minimum unchanged. ctx is nonnil, limit is positive, jobs is caller-owned and may remain open with sparse input. open cooperates with cancellation; it returns either a nonnil owned lease and nil error, or nil and an independent error. It may finish acquiring a lease after cancellation. Run cooperates too, including held cleanup before it returns. Close finishes but may be held and may fail.

Start ready jobs with spare capacity, including the first job before more input or channel closure. At most limit reservations are outstanding from admission/acquisition through completed Close. Each lease has its own lifecycle: wait for its Run before closing it exactly once; unrelated running leases do not delay that closure or future work in a released slot. No shared cohort release barrier is required. A successful acquisition whose Run never starts still needs Close.

On observed caller cancellation or independent Open, Run or Close failure, stop admitting affected work and request cooperative stop immediately, including while awaiting input, capacity, another acquisition or held cleanup. Wait for every admitted acquisition, started Run and owned Close before returning. Never launch Run after observing stop. Admission is a decision boundary; work admitted before a concurrent failure may already be starting. Never close the caller's jobs channel. An already-canceled caller admits no work.

Retain independently failing Open/Run/Close errors, including errors wrapping or joining context.Canceled or DeadlineExceeded. Only the exact worker-context standard error returned solely to acknowledge coordinated stopping may be suppressed when the caller did not cancel. If the caller cancels while stopping, preserve its standard classification and custom cause. Accepted effects remain accepted; complete uncanceled success returns nil. Keep the mechanism small; no framework, new dependency or panic-recovery policy.
