# Owned worker host

Keep Job, Lease and Serve(ctx,jobs,limit,open). Go 1.22 minimum; standard library only. Context is nonnil, limit positive, and input channel caller-owned. Open cooperates with its context; success returns a nonnil lease, failure nil plus error. Run cooperates with stop requests but can have deliberately held cleanup before returning. Open, Run and Close can fail independently.

Serve must start available jobs concurrently up to the declared capacity (tests use 2). Capacity bounds acquired leases until Close completes, including leases acquired before stopping prevents Run from starting. A batch implementation is acceptable; serial execution that cannot start another job while capacity is available is not. These leases share a lifecycle boundary: join every started Run in the current cohort before any acquired lease is closed. No further admission after an observed failure or cancellation. Request all affected work to stop, then wait for actual Run completion, close every successfully acquired lease exactly once, and wait for Close completion before returning. A successfully acquired lease whose Run never starts is still owned and closed after the cohort joins. Never close the caller's jobs channel.

Already-canceled calls open nothing and return cancellation. Cancellation must also interrupt waiting for input/admission, even when the caller leaves its channel open. Retain independent Open/Run/Close errors via errors.Is; coordinated context stop may additionally be reported. Caller cancellation observed while stopping remains inspectable. Successful job effects stay accepted. Completed uncanceled calls return nil. Preserve this host-supplied lifecycle API; add no dependency-construction framework or unrelated public API.
