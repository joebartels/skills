Added `CSV` as a value implementation of the existing `Encoder` protocol. It writes a `name,value` header even for empty input and delegates field escaping and write-error handling to `encoding/csv`. Added CSV quoting, empty-input, and writer-failure tests, plus a `reportkit_test` example in an external package implementing a host-defined encoder. A separate failing encoder test confirms `Report.Render` returns no partial bytes on failure.

I did not add an `Exporter` interface matching `Report`'s methods. There is no separate production Report implementation or caller needing that substitution; mirroring `Report` solely to mock it would add an abstraction without a real variation point. Tests can exercise the concrete `Report` with the existing host-implemented `Encoder` boundary, including its failure behavior.
