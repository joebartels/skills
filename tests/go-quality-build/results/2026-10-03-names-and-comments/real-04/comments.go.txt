// ResolveRequestID returns candidate if uids.IsValidRequestID accepts it.
// Otherwise it generates a new ID. rejected is true only when a nonempty
// candidate was replaced, allowing the caller to log the rejection.
//
// Invalid candidates are replaced rather than repaired so no caller-chosen
// fragment reaches logs. A valid ID does not establish its origin: services
// facing untrusted callers must strip X-Request-Id unless a trusted proxy
// mints it. Upstream IDs in another format are replaced and warned about on
// every request; accepting that format requires changing uids.IsValidRequestID,
// not configuration.
