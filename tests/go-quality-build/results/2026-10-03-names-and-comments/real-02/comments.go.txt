// ResolveRequestID resolves the candidate from a request's X-Request-Id header.
// An empty candidate gets a new ID with rejected=false. A candidate accepted by
// uids.IsValidRequestID is returned unchanged. Any other candidate gets a new ID
// with rejected=true.
//
// Invalid candidates are replaced rather than repaired to keep their contents
// out of logs. Validity does not establish who minted an ID: services facing
// untrusted callers must strip the header unless a trusted proxy mints it.
// Accepting another ID format requires changing uids.IsValidRequestID.
func ResolveRequestID(candidate string) (id string, rejected bool)
