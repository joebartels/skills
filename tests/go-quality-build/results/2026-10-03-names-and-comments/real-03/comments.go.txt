// ResolveRequestID resolves candidate from the X-Request-Id header. It returns
// candidate unchanged if uids.IsValidRequestID accepts it; otherwise it returns
// a new ID. rejected is true only when a non-empty candidate was replaced.
//
// Invalid candidates are replaced rather than repaired to keep their fragments
// out of logs. A valid ID does not establish its origin: services facing
// untrusted callers must strip the header unless a trusted proxy mints it.
// Upstream IDs in an unsupported format are replaced and warned about on each
// request. Accepting another format requires changing uids.IsValidRequestID;
// it is not configurable.
func ResolveRequestID(candidate string) (id string, rejected bool)
