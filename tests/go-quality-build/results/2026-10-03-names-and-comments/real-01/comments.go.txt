// ResolveRequestID resolves a candidate from the X-Request-Id header. An empty
// candidate gets a new ID with rejected=false. A candidate accepted by
// uids.IsValidRequestID is returned unchanged; any other candidate gets a new
// ID with rejected=true.
//
// Invalid candidates are replaced rather than repaired to keep their fragments
// out of logs. Validation does not establish who minted an ID: services must
// strip the header from untrusted callers unless a trusted proxy mints it.
// Accepting another ID format requires changing uids.IsValidRequestID, not
// configuration.
